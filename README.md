## 👨‍💻 About me

I currently work as a **Tech Lead**, leading engineers and contributing directly
to architecture decisions, requirements refinement, code reviews, mentoring and
the technical evolution of a distributed energy product.

Throughout my career, I have worked with backend systems, REST and GraphQL APIs,
event-driven architectures, asynchronous processing, cloud infrastructure,
observability and production reliability.

My experience includes:

- Technical leadership and mentoring of engineering teams;
- Architecture and development of backend services with Java, Node.js, Ruby, Python and Go;
- Distributed systems, queues, messaging and asynchronous workflows;
- AWS environments, containers, Kubernetes, Helm, KEDA and Infrastructure as Code;
- Observability with New Relic, including custom metrics, alerts and incident monitoring;
- AI-assisted software development using Claude Code, Codex and multi-agent workflows;
- Web scraping and automated data collection using crawlers, proxies and captcha-solving integrations.
